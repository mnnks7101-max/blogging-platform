# 📝 My Blogging Platform

A simple and modern blogging platform where users can register, log in, create blog posts, edit and delete their posts, and interact through comments.

## 🚀 Features

- User registration and login
- User authentication
- Create blog posts
- Edit blog posts
- Delete blog posts
- Comment on blog posts
- SQLite database integration
- RESTful API
- Responsive and modern UI
- API testing using Thunder Client

## 🛠️ Technologies Used

- Python
- Flask
- Flask-SQLAlchemy
- Flask-Login
- SQLite
- HTML
- CSS
- REST API
- Thunder Client

## 🔌 REST API

| Method | Endpoint | Description |
|--------|----------|-------------|
| GET | `/api/posts` | Get all posts |
| GET | `/api/posts/<id>` | Get a single post |
| POST | `/api/posts` | Create a post |
| PUT | `/api/posts/<id>` | Update a post |
| DELETE | `/api/posts/<id>` | Delete a post |
